\# 肥胖相关因素统计分析：非参数检验与稳健推断



\## 项目简介



本项目基于肥胖相关调查数据，对人口属性、生活方式因素与 BMI（Body Mass Index，身体质量指数）之间的统计关联进行分析。



项目重点不在于单纯建立一个预测模型，而是从统计推断角度回答以下问题：



1\. 不同性别、年龄段人群的 BMI 分布是否存在显著差异；

2\. 饮食习惯、运动频率、家族肥胖史、交通方式等因素是否与 BMI 存在统计关联；

3\. 在控制年龄与性别后，这些因素是否仍能提供额外的解释信息；

4\. 多变量 OLS 回归的经典假设是否成立；

5\. 当存在非正态性或异方差时，传统 OLS 推断是否仍然可靠；

6\. 使用 HC3 稳健标准误和 Case Bootstrap 后，主要统计结论是否保持稳定。



本项目强调\*\*统计关联与稳健性分析\*\*，不将观察性数据中的相关关系解释为因果关系。

\## 数据说明



原始数据包含约 2 万条观测记录，主要变量包括：



| 变量 | 含义 |

|---|---|

| Gender | 性别 |

| Age | 年龄 |

| Height | 身高 |

| Weight | 体重 |

| family\_history\_with\_overweight | 是否具有超重/肥胖家族史 |

| FAVC | 是否经常摄入高热量食物 |

| FCVC | 蔬菜摄入频率 |

| CAEC | 两餐之间进食情况 |

| SMOKE | 是否吸烟 |

| CH2O | 饮水量 |

| SCC | 是否监控热量摄入 |

BMI 根据身高与体重计算：



\\\[

\\]



年龄进一步划分为：



\- 20 岁以下

\- 20–30 岁

\- 30–45 岁

\- 45 岁以上

\## 分析流程



项目采用以下统计分析流程：



```text

数据读取与清洗

&#x20;       ↓

BMI 构造与年龄分组

&#x20;       ↓

描述性统计与可视化

&#x20;       ↓

非参数组间比较

├─ Wilcoxon 秩和检验

├─ Kruskal-Wallis 检验

└─ Dunn 事后比较 + Bonferroni 校正

&#x20;       ↓

控制年龄和性别后的秩变换分析

&#x20;       ↓

多变量 OLS 回归

&#x20;       ↓

OLS 模型诊断

├─ Anderson-Darling 正态性检验

├─ Breusch-Pagan 异方差检验

└─ VIF 多重共线性诊断

&#x20;       ↓

HC3 异方差稳健标准误

&#x20;       ↓

Case Bootstrap

&#x20;       ↓

OLS / HC3 / Bootstrap 结果比较

```

\## 1. 描述性统计与 BMI 分布



首先按照性别和年龄段统计：



\- 样本量

\- BMI 均值

\- BMI 中位数

\- 标准差

\- 第一四分位数

\- 第三四分位数



并绘制不同年龄段、不同性别人群的 BMI 箱线图。



!\[不同性别与年龄段的 BMI 分布](outputs/01\_BMI\_性别年龄段分布.png)



从图中可以直观看到，不同年龄段的 BMI 分布存在明显差异，同时部分年龄组内部也存在一定的性别差异。



由于各年龄段样本数量可能并不均衡，因此图形结果主要用于描述数据结构，正式推断仍需结合后续统计检验。



\---



\## 2. 非参数组间比较



考虑到 BMI 的分布可能偏离正态分布，本项目首先采用非参数方法进行组间比较。



\### 性别差异



使用 Wilcoxon 秩和检验比较不同性别人群的 BMI 分布。



\### 年龄组差异



使用 Kruskal-Wallis 检验判断多个年龄组之间是否存在总体差异。



若总体检验显著，则进一步使用 Dunn 检验进行两两比较，并采用 Bonferroni 方法对多重检验的 P 值进行校正。



相关结果保存在：



```text

outputs/02\_nonparametric\_tests.csv

outputs/03\_age\_Dunn\_Bonferroni.csv

```



\---



\## 3. 控制年龄与性别后的秩变换分析



单纯的组间比较可能受到年龄、性别等人口属性的混杂影响。



因此，本项目进一步将 BMI 转换为秩，并比较两个嵌套模型：



```text

简化模型：

BMI\_rank \~ Age + Gender



完整模型：

BMI\_rank \~ Age + Gender + Target\_Factor

```



通过比较两个模型，判断目标因素在控制年龄与性别以后，是否仍能提供额外的统计解释信息。



分析因素包括：



\- 高热量食物摄入（FAVC）

\- 超重/肥胖家族史

\- 两餐之间进食情况（CAEC）

\- 体育活动频率（FAF）

\- 交通方式（MTRANS）



该部分用于稳健的关联分析，不用于因果推断。



结果保存在：



```text

outputs/04\_rank\_adjusted\_tests.csv

```



\---



\## 4. 多变量 OLS 回归



随后建立多变量线性回归模型，以 BMI 为因变量，同时纳入人口属性和生活方式变量。



模型形式为：



\\\[

BMI =

\\beta\_0+

\\beta\_1Gender+

\\beta\_2Age+

\\beta\_3FamilyHistory+

\\cdots+

\\varepsilon

\\]



其中连续变量：



\- Age

\- FCVC

\- NCP

\- CH2O

\- FAF

\- TUE



在建模前进行标准化处理，从而减少量纲差异，并提高不同连续变量系数之间的可比性。



因此，对于这些连续变量，回归系数应解释为：



> 当该变量增加 1 个标准差时，在控制其他变量不变的情况下，BMI 平均变化多少。



而不能直接解释为原始变量增加一个单位所对应的 BMI 变化。



模型拟合结果保存在：



```text

outputs/05\_OLS\_model\_fit.csv

```



\---



\## 5. OLS 模型诊断



线性回归的统计推断依赖一系列模型假设，因此项目并未直接根据 OLS 的 P 值得出最终结论，而是进一步检查模型残差。



\### 5.1 残差正态性



使用 Anderson-Darling 检验，并结合 Q-Q 图判断残差是否明显偏离正态分布。



!\[OLS 残差 Q-Q 图](outputs/02\_OLS\_residual\_QQ.png)



从 Q-Q 图可以看到，大部分中间区域较接近理论直线，但尾部存在一定偏离。



对于大样本数据，正式正态性检验通常对轻微偏离也非常敏感，因此需要同时结合图形诊断，而不能机械地只根据 P 值判断。



\### 5.2 异方差



使用 Breusch-Pagan 检验检测残差方差是否保持恒定。



同时绘制残差与拟合值关系：



!\[OLS 残差与拟合值](outputs/03\_OLS\_residual\_vs\_fitted.png)



图中残差并未完全随机地围绕 0 分布，同时平滑曲线呈现一定结构，说明模型可能存在：



\- 异方差；

\- 非线性结构；

\- 尚未被模型充分描述的数据模式。



因此，仅依赖经典 OLS 标准误可能并不充分。



\### 5.3 多重共线性



使用 VIF（Variance Inflation Factor）检查解释变量之间是否存在明显的多重共线性。



诊断结果保存在：



```text

outputs/06\_model\_diagnostics.csv

outputs/07\_VIF.csv

```

\## 6. HC3 异方差稳健标准误



考虑到 OLS 中可能存在异方差，本项目进一步采用 HC3 协方差估计器重新计算回归系数的：



\- 标准误

\- P 值

\- 95% 置信区间



HC3 不改变 OLS 的系数点估计，而是对其方差估计进行稳健修正。



因此可以比较：



```text

传统 OLS 推断

&#x20;       vs

HC3 稳健推断

```



用于判断主要结论是否依赖于经典同方差假设。



结果保存在：



```text

outputs/08\_OLS\_vs\_HC3.csv

```



\---



\## 7. Case Bootstrap 稳健性分析



为了进一步降低对参数分布假设的依赖，本项目进行了 Case Bootstrap。



具体方法为：



1\. 从原始样本中进行有放回抽样；

2\. 每次重新抽取与原样本相同数量的观测；

3\. 在 Bootstrap 样本上重新拟合完整 OLS 模型；

4\. 重复 1000 次；

5\. 根据 Bootstrap 系数经验分布计算 95% 置信区间。



随机种子设置为：



```r

SEED <- 42

```



Bootstrap 次数为：



```r

BOOT\_B <- 1000

```



该方法直接对观测记录进行重抽样，因此不要求所有残差具有完全相同的方差结构。



但它仍然依赖观测之间近似独立，所以该分析的目的仍然是\*\*推断稳健性检查，而不是因果识别\*\*。



\---



\## 8. OLS、HC3 与 Bootstrap 的比较



最后，将三种方法得到的 95% 置信区间进行比较：



\- 传统 OLS

\- HC3 稳健标准误

\- Case Bootstrap



!\[OLS、HC3 与 Case Bootstrap 95% 置信区间](outputs/04\_置信区间稳健性比较.png)



如果某个因素在三种方法下：



\- 系数方向一致；

\- 置信区间位置接近；

\- 显著性判断保持一致；



则说明该统计结论对标准误估计方法具有较好的稳健性。



完整结果保存在：



```text

outputs/09\_interval\_comparison.csv

outputs/10\_robustness\_summary.csv

```

\## 项目特点



与单纯建立一个回归模型不同，本项目更加关注\*\*统计推断是否可靠\*\*。



项目完整经历了：



```text

发现数据分布问题

&#x20;       ↓

采用非参数方法

&#x20;       ↓

建立多变量模型

&#x20;       ↓

检查模型假设

&#x20;       ↓

发现经典假设不足

&#x20;       ↓

采用 HC3 修正

&#x20;       ↓

使用 Bootstrap 再次验证

&#x20;       ↓

```



因此，本项目重点展示的并不是某一种单独算法，而是从数据探索、统计检验、模型诊断到稳健推断的完整统计分析流程。

\## 局限性



本项目仍存在以下限制：



1\. 数据属于观察性数据，因此统计关联不能直接解释为因果关系；

2\. 不同年龄组的样本量可能存在明显不平衡；

3\. 残差图提示线性模型可能无法完整描述所有非线性关系；

4\. HC3 可以改善异方差条件下的标准误估计，但无法解决模型函数形式设定错误；

5\. Bootstrap 可以用于检验统计推断的稳定性，但并不能自动消除混杂偏差；

6\. 部分行为变量属于调查指标，对真实生活方式的测量可能存在一定误差。



未来可以进一步尝试：



\- 非线性模型；

\- GAM；

\- 样条回归；

\- 交互效应；

\- 更系统的模型选择；

\- 将肥胖等级作为分类响应变量进行预测建模。
